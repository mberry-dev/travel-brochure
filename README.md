# Travel Brochure

A visually designed travel destination website built to showcase front-end layout and design skills.

A polished, responsive travel brochure site highlighting a destination with rich visuals, structured layout, and clean typography.

## Features
- Responsive design
- Clean visual layout and typography
- Destination highlights and imagery

## Built With
- HTML, CSS

## How to Run
1. Clone the repo
2. Open `index.html` in your browser
